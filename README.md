CoreRush
CoreRush is a Game Prototype for a Arena Shooter
Uses mainly C# in Unity
## 🚀 Getting Started

Follow these steps to download the prototype and open it on your machine using Unity and VS Code.

### 1. Prerequisites
Before you begin, ensure you have the following installed:
*   **Unity Hub** & **Unity Version:** `[6000.5.9f1]`
*   **Visual Studio Code** (with the *Unity* extension pack installed)
*   **Git** (optional, for cloning)

### 2. Download the Project
You can get the project files in one of two ways:

#### Option A: Clone the Repository (Recommended)
Open your terminal or command prompt and run:
```bash
git clone https://github.com
```

#### Option B: Download the ZIP
1. Click the green **Code** button at the top right of this GitHub page.
2. Click **Download ZIP**.
3. Extract the downloaded ZIP file to a folder on your computer.

### 3. Open in Unity
1. Open **Unity Hub**.
2. Click the **Add** button (or **Open** > **Add project from disk**).
3. Navigate to the extracted folder, select the main project directory, and click **Add Project**.
4. Click on the project in Unity Hub to launch it. *(Note: The first launch may take a few minutes to generate library files).*

### 4. Open in VS Code (For Code Editing)
To view and edit scripts with proper IntelliSense autocomplete:
1. Open **Unity Editor**.
2. Go to **Edit** > **Preferences** (on Mac: **Unity** > **Preferences**).
3. Select the **External Tools** tab.
4. Set the **External Script Editor** dropdown to **Visual Studio Code**.
5. Regenerate project files if prompted.
6. Double-click any C# script inside Unity, and it will automatically open the entire project workspace inside VS Code.
